
# Lab 4: Control Structures in C++

## Objective
To understand decision-making statements and loops in C++.

## Tasks
1. Pass or Fail using if-else.
2. Check Even or Odd numbers.
3. Find the larger of two numbers.
4. Print numbers 1 to 20 using for and while loops.
5. Print a star pattern using nested loops.

## Concepts Used
- if-else statements
- Modulus operator (%)
- for and while loops
- Nested loops

## Language
C++
